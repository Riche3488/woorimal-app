## 6단계: 버전 출시

### 1.0.0 (versionCode 6) — 비공개 테스트용

AAB: EAS 빌드 93bb9ed0(2026-11-24, 커밋 c0e1539). versionCode 5(빌드 1286590a)는 Play가 "필수 하드웨어 기능 `android.hardware.screen.portrait`" 문제로 검토 전송을 막아서 쓰지 않는다. 6은 세로 화면 기능을 선택사항(`required="false"`)으로 선언했다(`plugins/with-optional-portrait.js`). 내부 테스트에 먼저 올려 확인한 뒤 비공개 테스트로 승격한다.

출시 이름(Console 안에서만 보임, 50자 이내): `1.0.0 (6) 비공개 테스트`. 앱 이름("우리말 곳간 - 맞춤법·띄어쓰기 퀴즈")은 출시 이름 칸이 아니라 스토어 등록정보에 넣는다

출시 노트(500자 이내, 293자. 태그째 붙여 넣기):


| 질문 | 답 |
| --- | --- |
| 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **아니요** |
| (위가 아니요면 나머지 질문은 생략됨) | |

근거: 앱은 서버에 아무것도 보내지 않는다. 묶음 내려받기는 읽기 전용 HTTPS 요청이고 기록·기기 정보를 붙이지 않는다. 기기 저장(AsyncStorage)은 "수집"이 아니다. 문제 신고는 브라우저로 웹 화면을 열고, 그 뒤 처리는 웹 방침을 따른다. 1.0.0(5)의 플레이 진단 기록은 기본 꺼짐·기기 저장이고, 내보내기는 이용자가 시스템 공유 창에서 직접 보낼 곳을 고르는 동작이라 "수집"이 아니다(방침 2·5항에 적음, 2026-11-24). 광고 ID·위치·연락처 권한을 쓰지 않는다(AD_ID 권한 없음).
