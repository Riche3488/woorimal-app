#### 광고 넣을 때 점검 목록

1차(1.0.0)는 광고 SDK가 없으므로 "광고 없음"으로 신고한다. Play의 광고 신고는 **지금 올리는 버전**에 광고가 있는지를 묻는 것이고, 앞으로의 계획까지 적으라는 뜻이 아니다(2026-11-25 판단). 광고를 넣는 버전을 **검토에 보내기 전에** 아래를 모두 고친다. 신고 내용과 실제 앱이 다르면 거부되거나 앱이 내려갈 수 있다.

- [ ] 앱 콘텐츠 > 광고: "예, 앱에 광고가 있습니다"로 바꾼다. 스토어에 "광고 포함" 표시가 붙는다
- [ ] 앱 콘텐츠 > 광고 ID: AdMob 등은 `com.google.android.gms.permission.AD_ID` 권한을 넣는다. [listing.md](store/listing.md)의 "광고 ID: 사용 안 함"을 "사용(광고)"으로 바꾸고 Console에서도 같이 신고한다. 빌드한 AAB의 매니페스트에 권한이 실제로 들어갔는지 확인한다
- [ ] 데이터 보안 양식: 지금의 "수집 안 함"을 고친다. 광고 SDK가 수집·공유하는 항목(기기 또는 기타 ID, 앱 상호작용, 대략적 위치 등)을 SDK의 공식 데이터 보안 안내대로 적는다
- [ ] 개인정보처리방침: 웹 `public/app/privacy.html`(웹 저장소)에 광고 SDK 이름, 수집 항목, 맞춤 광고 끄는 방법을 적고 배포한다. 데이터 보안 양식과 내용이 맞아야 한다
- [ ] 스토어 설명: [listing.md](store/listing.md)의 "회원 가입, 광고, 분석 도구가 없습니다" 문구를 고치고 Console 자세한 설명에도 반영한다. 비공개 테스트 모집 글의 "광고 없음"도 더는 쓰지 않는다
