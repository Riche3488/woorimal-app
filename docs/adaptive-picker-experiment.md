# 개인화 출제 실험

개인화는 개발·preview 빌드의 설정에서 명시적으로 켜서 검증한다. production에서는 활성화하지 않는다. 현재 기준선·사용자 정답률·완주율의 비교 관찰 결과는 아직 없다.

유형과 실제 풀이 방식별로 최근 독립 제출 20개를 기기에 보관한다. 힌트 뒤 재시도·시간 초과·포기는 난도 추정 표본에 넣지 않는다. 입력과 보기를 섞어 과거 실력을 추정하지 않으며 기존 누적 성적은 그대로 유지한다. 앱이 백그라운드에 머문 시간은 풀이 시간에 포함하지 않는다. 이 기록은 복습·출제 기능을 위한 기기 내 상태로 선택적 진단 내보내기와 구분한다.

충분한 최근 기록이 없으면 쉬운 문제를 우선한다. 충분한 후보와 최근 정답률 85% 이상인 경우에 일반 10문제를 쉬움 3·적정 5·도전 2, 퀵 5문제를 2·2·1로 구성한다. 도전 후보는 `level: hard`, 쉬움은 그 외 `easy: true`, 나머지는 적정으로 시작한다. 85% 미만이면 도전 후보를 제외하고 빈자리는 쉬움·적정으로 채운다. 이 분류는 문제 난도의 실측 추정이 아니라 초기 규칙이다.

예정 복습은 일반 최대 2개·퀵 최대 1개를 먼저 배정한다. 반응시간은 같은 풀이 방식의 기록 10개 이상일 때 같은 복습일의 후보 순서를 정하는 보조 정보로만 사용한다. 느리게 맞혔다는 이유로 낱알을 줄이지 않는다. 오늘의 문제·유형 연습·복습·담은 문제에는 개인화 구성을 적용하지 않는다.

검증은 동일 문제 묶음에서 고정 시드 200개로 기본·개인화 출제를 재현해 문항 수·중복 정답·보기 유효성·복습 상한·후보 고갈을 확인한다. 관찰에서는 입력 설정·최근 시도 수·첫 세 문제 정오답·중도 종료·완주율을 구분해 기록한다. 충분한 사용자 표본과 비교 기간을 확보한 뒤 production 기본 적용 여부와 60%/85% 기준·구성비를 재검토한다.
