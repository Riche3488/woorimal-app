# 플레이 성장과 초기 장식

곳간 레벨은 누적 낱알을, 도감은 발견과 날짜를 둔 복습 성취를 보여 준다. 퀴즈·카드·퍼즐의 서로 다른 학습 항목 5개가 하루 목표에 기여하며, 오답도 독립적으로 답을 제출했다면 학습으로 인정한다.

초기 장식은 하루 목표 첫 달성의 나뭇잎 깃발, 발견 10낱말의 낱말 팻말, 간격 복습 완료 5낱말의 도토리 바구니다. 해금은 한 번만 저장하며 장착·해제는 도감에서 한다. 기존 사용자의 유효한 문제 기록도 발견과 복습 완료에 반영한다.

화면은 기존 한지 배경과 곳간 자산 위에 코드로 만든 작은 장식을 겹친다. 구매나 별도 재화 없이 조건과 현재 장착 상태를 보여 준다. 주요 진행 변화에는 기존 Pop 연출을 재사용하고, 동작 줄이기에서는 정적 진행과 문구로 같은 정보를 전달한다.

퀴즈 낱알은 판 완료 전까지 예상값으로 표시한다. 저장된 보상 영수증으로 중복 지급을 막으며, 목표 달성 뒤에는 마무리 인사를 우선한다. 실제 기기에서 읽기·터치·장식 위치를 확인한 결과는 별도 검증 기록에 남긴다.

## 장식 12종과 도감 (2026-11-25)

장식은 이미 저장된 기록으로 해금한다(`src/core/decorations.ts`, 한 번 얻으면 남는다).

| 등급 | 장식 | 조건 |
| --- | --- | --- |
| 흔함 | 나뭇잎 깃발 · 낱말 팻말 · 허수아비 · 장독대 · 방패연 | 하루 목표 첫 달성 · 낱말 10개 발견 · 퀴즈 5판 · 3일 연속 · 퍼즐 10낱말 |
| 귀함 | 도토리 바구니 · 석등 · 감나무 · 서안과 벼루 · 까치 | 복습 마친 낱말 5개 · 7일 연속 · 5레벨 · 낱말 50개 발견 · 오늘의 문제 7번 |
| 아주 귀함 | 물레방아 · 황금 박 | 12레벨 · 복습 마친 낱말 30개 |

- 디오라마 자리 3곳(왼쪽 끝·곳간 왼쪽 모서리 앞·오른쪽 끝)에 동시에 놓는다. 저장은 `equipped: [id|null ×3]`, 예전 문자열 하나는 첫 자리로 옮긴다.
- 장식 도감(곳간 낱말 화면 위쪽): 모은 수 n/12와 진행 막대, 잠긴 장식은 실루엣과 '조건 · 지금/목표'. 자리가 꽉 차면 장착 대신 안내 문구를 보인다.
- 새로 얻음: `seen`에 없는 해금 장식. 결과 화면에 '새 장식을 얻었어요!' 카드, 홈 '곳간 꾸미기' 줄에 NEW 배지. 도감을 열면 확인한 것으로 바꾸되 그 화면에서는 NEW를 남긴다. 업데이트 전에 이미 얻은 장식은 확인한 것으로 본다.
