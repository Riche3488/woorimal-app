# 디자인 가이드: 한지 디오라마

작성일: 2026-11-20 · 적용: 홈·게임·결과·기록·오답노트·설정·아이콘·스플래시

## 콘셉트

손바닥만 한 한지 상자 속 미니어처 곳간 마을. 문제를 맞힐 때마다 낱알이 쌓이고, 다람쥐가 자라고, 곳간이 초가 → 기와 → 큰 곳간으로 커진다. 앱의 핵심 고리(정답 → 낱알 → 성장)를 그림이 그대로 말하게 한다.

검토한 다른 방향:

| 방향 | 장점 | 뺀 이유 |
| --- | --- | --- |
| **한지 디오라마** ← 선택 | 기존 한지 색과 성장 장치를 살림, 긴 문제 글이 잘 읽힘, 자산 수가 적음 | — |
| 먹과 금박(어두운 바탕·금박·붓글씨) | 가장 고급스러움 | 어두운 바탕에서 긴 문제 글 가독성↓, 정체성을 통째로 바꿔야 함 |
| 사계절 들판(계절·시간대별 3D 풍경) | 가장 몰입감 큼 | 배경이 많이 필요해 비용·앱 용량이 큼 |

## 글꼴 (`T`)

- 제목·숫자: **고운바탕 Bold**(OFL). 한지·서책 느낌의 명조. `assets/fonts/GowunBatang-Bold.ttf`는 KS X 1001 한글 2,350자 + ASCII + 문장부호만 남긴 부분 글꼴(8.2MB → 1.37MB). 없는 글자는 시스템 글꼴로 대신 그려진다.
- 본문·문제 글·버튼 설명: 시스템 산세리프(가독성 우선).
- 스케일: `display 30` · `title 22` · `heading 17` · `body 16` · `caption 13`.

## 3D 렌더 규칙 (생성 자산 공통)

- 무광 클레이 + 비닐 토이 질감, 둥근 덩어리 형태, 디테일은 단순하게
- 왼쪽 위 따뜻한 아침 햇살, 부드러운 접지 그림자
- 3/4 시점, 같은 바닥선
- 팔레트: 한지 크림 · 낱알 금빛 · 단청 주홍 · 먹 갈색 · 솔잎 초록
- 모든 자산은 기준 다람쥐(A1)를 참조 이미지로 넣어 만든다 → `docs/design/assets.md`

## 컴포넌트

- **종이 카드** (`paperCard`): `paper` 바탕 + 1px `line` 테두리 + 낮은 그림자. 흰 카드 대신 쓴다.
- **주 버튼**: 먹 바탕, 고운바탕 금빛 글자, 아래 4px 짙은 테두리. 누르면 2px 내려앉는다(`PressableScale`).
- **보기 버튼**: 종이 + 아래 3px 테두리. 누르면 내려앉고 낱알빛으로 물든다.
- **칩**: 둥근 알약(`R.pill`) — 연속 기록, 오늘 목표(낱알 아이콘 3개), 도토리.
- **도장**: 단청 주홍 사각에 고운바탕 글자, -4° 기울임 — '오늘의 문제'.
- 이모지 대신: 하트 `♥`(벡터 글리프, 색으로 상태 표시), 낱알·도토리·다람쥐·곳간은 3D 그림, 별 `★/☆`. 🔥(연속)과 🟩🟥(공유 결과)는 의미가 굳은 기호라 남겼다.

## 움직임 (`src/ui/motion.ts`, Reanimated 4)

원칙: 의미 있을 때만, 짧게, 반복은 느리고 작게.

| 순간 | 움직임 | 길이 |
| --- | --- | --- |
| 화면 등장 | 아래에서 떠오름, 60ms씩 차례로(`enterUp`) | 260ms |
| 홈 디오라마 | 곳간 단계별 5초 반복 영상(숨쉬기·꼬리·나무) | 5s 반복 |
| 경험치 바 | 0(또는 이전 값)에서 새 값으로 | 840~900ms |
| 정답 | 낱알 7알이 위로 흩어짐 + 낱알 숫자 톡 + 성공 햅틱 | 700ms |
| 오답·시간 초과 | 피드백 카드 좌우 흔들림 + 하트가 커졌다 빛이 빠짐 + 오류 햅틱 | 275ms |
| 남은 시간 25% 아래 | 타이머 바 맥박 | 520ms 반복 |
| 레벨업 | 환호 영상 1회 재생 후 정지 + "레벨 업!" 톡 | 5s |
| 결과 다람쥐 | 정답률 80%↑ 환호, 40%↓ 책 읽기, 그 사이 기본 포즈 + 느린 떠다님 | 3s 반복 |
| 화면 전환 | 게임은 아래에서 올라옴, 결과는 아래에서 페이드, 나머지 페이드 | 시스템 |

**움직임 줄이기**: 시스템 '애니메이션 제거'가 켜지면 `useReducedMotion()`으로 영상은 정지 그림(영상 첫 프레임), 반복·파티클·흔들림은 끄고 결과를 바로 보인다. 햅틱은 설정의 '진동'을 따른다.

## 성능 규칙

- 그림은 WebP(투명은 yuva420p), 화면 크기의 2~3배 해상도까지만(다람쥐·곳간 480px, 아이콘 128px)
- 영상은 H.264 720×720, 소리 없음, faststart. 반복 영상 하나 약 70KB
- 영상은 화면에 보일 때만 재생(`useFocusEffect`), 첫 프레임을 그리기 전에는 같은 장면의 정지 그림을 깐다 → 레이아웃 밀림 없음
- 게임 화면에는 영상·반복 배경이 없다(문제에 집중)
- 파티클은 한 번에 7개
- 앱은 실행 중에 외부 생성 서비스를 부르지 않는다. 모든 자산은 번들된 정적 파일
