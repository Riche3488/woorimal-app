# 우리말 탐험 지도 후속 설계

기존 문제를 숲의 짧은 스테이지로 묶어 진행감을 제공한다. 공통 세션·학습 활동·낱알·도감을 재사용하고 새 문제 은행이나 별도 재화를 만들지 않는다. R1~R3 관찰 후 별도 구현 계획으로 진행할 범위다.

## 첫 범위

세 스테이지를 순서대로 제시한다: 낱말 숲(뜻·첫소리), 바른말 길(맞춤법·쓰임), 속담 쉼터(속담). 각 스테이지는 최대 5문제이며 시간제한·하트 없이 끝까지 풀 수 있다. 정답 수와 완주는 별도 표시하고, 다음 스테이지는 완주로 연다. 최초 독립 정답 3개는 추가 성취 표시에 쓰되 잠금 해제 조건으로 사용하지 않는다.

후보가 3개 미만인 주제는 표시하지 않는다. 동의어·같은 정답 중복·보기 변환의 안전 규칙을 재사용한다. 스테이지 시작 때 문제·보기·묶음 버전을 고정하고 일반 세션처럼 중단·복구한다. 지도 진행은 완료 영수증의 세션 식별자로 한 번만 반영한다.

현재 누적 낱알에 추가로 반복 스테이지 완료 보너스를 주지 않는다. 당일 같은 문항의 중복 보상 방지를 유지하며, 최초 지역 완료의 장식은 기존 세 장식 사용을 관찰한 뒤 제작량과 해금 조건을 정한다. 새 배경은 별도 자산 검토 대상이다.

## 저장과 인수 조건

별도 구현에서는 `adventure.version`, `completedStageIds`, `stageBestIndependentCorrect`를 추가한다. 완료한 스테이지는 문제 묶음에서 문항이 빠져도 취소하지 않으며 새 플레이만 현재 후보로 만든다. 사용자에게 완주·독립 정답·도움받은 해결을 구분해 보여 준다.

인수 조건은 단계별 후보 고갈, 오답만 낸 완주, 잠금 해제 재호출, 중단 복구, 당일 반복 보상, 기존 미션·도감과의 중복, 묶음 교체 후 기존 진행 보존이다. 지도 버튼을 추가하기 전에 홈의 시작·복습 선택이 더 복잡해지지 않는지 사용자 관찰로 확인한다.
