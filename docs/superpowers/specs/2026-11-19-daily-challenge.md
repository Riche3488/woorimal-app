# 오늘의 문제 + 결과 공유

## 목적
매일 돌아올 이유를 만들고, 결과를 공유해 입소문이 나게 한다. 서버 없이 날짜만으로 같은 날에는 모든 사용자에게 같은 문제를 낸다.

## 규칙 (`src/core/challenge.ts`)
- `CHALLENGE_SIZE = 5`. 회차 번호는 `2026-11-19`를 1회로 하루에 1씩(`challengeNumber`).
- 출제(`pickChallenge(questions, day)`): 날짜 문자열의 해시를 시드로 하는 난수(mulberry32)를 쓴다. 문제를 key 순으로 정렬한 뒤 유형 순서를 섞고, 유형마다 하나씩 돌아가며 뽑는다(유형이 겹치지 않게). 보기 순서도 같은 시드로 섞는다. 같은 묶음이면 기기와 관계없이 결과가 같고, 개인 기록(`progress`)은 쓰지 않는다.
  - 묶음이 갱신되는 동안에는 사용자마다 다른 문제가 나올 수 있다. 받아들인다.
- 하트 제한 없이 5문제를 모두 푼다(`startRound`의 하트 수를 5로, 화면에서 하트를 숨김).
- 표시: 맞힘 `o` 🟩, 틀림 `x` 🟥, 시간 초과 `t` ⏰ (`marksFor`).
- 공유 글(`shareText`):
  ```
  우리말 곳간 오늘의 문제 #1
  🟩🟩🟥🟩⏰ 3/5
  🔥 4일 연속
  https://woorimal-contest.co.kr
  ```
  연속 기록이 0이면 그 줄은 뺀다. 공유는 React Native 기본 `Share`(의존성 추가 없음).

## 저장
- `challenge: { day: string | null, marks: string }`. 끝까지 푼 판만 기록한다(중간에 나가면 다시 풀 수 있음. 1차는 받아들임).
- 오늘의 문제도 낱알·문제 기록·연속 기록·하루 목표에 똑같이 들어간다.

## 화면
- 홈: 큰 시작 버튼 위에 "오늘의 문제 #n · 5문제" 카드. 풀었으면 "🟩🟩🟥🟩⏰ 3/5 · 공유하기"로 바뀌고 누르면 공유.
- 게임: 오늘 이미 풀었으면 문제를 내지 않고 안내한다.
- 결과: 오늘의 문제였으면 칸 표시와 "결과 공유" 버튼.
