# 오늘의 문제 + 결과 공유

## 목적
매일 돌아올 이유를 만들고, 결과를 공유해 입소문이 나게 한다. 서버 없이 날짜만으로 같은 날에는 모든 사용자에게 같은 문제를 낸다.

## 규칙 (`src/core/challenge.ts`)
- `CHALLENGE_SIZE = 5`. 회차 번호는 `2026-11-19`를 1회로 하루에 1씩(`challengeNumber`).
- 출제(`pickChallenge(questions, day)`): 문제와 유형마다 `hash("woorimal:날짜:key")`로 점수를 따로 매겨 낮은 것부터 고른다(묶음 전체를 섞지 않음). 유형은 점수 순 5개, 겹치지 않게. 보기 순서도 "날짜:key" 시드로 섞는다. 개인 기록(`progress`)은 쓰지 않는다.
  - 난이도: 앞 3문제는 쉬운 문제(`easy`), 뒤 2문제는 변별 문제(`easy: false`). 그 유형에 해당 난이도가 없으면 다른 난이도로 채우고, 쉬운 문제를 앞에 둔다.
  - 안정성: 뽑히지 않은 문제가 늘거나 빠져도 그날 문제는 그대로다. 뽑힌 문제가 빠지거나 새 문제가 더 낮은 점수를 받을 때만 그 한 자리가 바뀐다(실제 묶음에 5% 삭제·200개 추가를 흉내 내면 60일 중 46일 완전히 같음).
  - 완전히 같게 하려면(나중): 웹 빌드가 앞으로 N일치 문제 key를 묶음에 넣고 앱이 그대로 쓴다. 묶음 형식이 바뀌므로 두 저장소를 함께 고친다.
- 하트 제한 없이 5문제를 모두 푼다(`startRound`의 하트 수를 5로, 화면에서 하트를 숨김).
- 표시: 맞힘 `o` 🟩, 틀림 `x` 🟥, 시간 초과 `t` ⏰ (`marksFor`).
- 공유 글(`shareText`):
  ```
  우리말 곳간 오늘의 문제 #1
  🟩🟩🟥🟩⏰ 3/5
  🔥 4일 연속
  https://woorimal-contest.co.kr
  ```
  연속 기록이 0이면 그 줄은 뺀다. 공유는 React Native 기본 `Share`(의존성 추가 없음). 공유 주소는 스토어 출시 뒤 바꿀 예정.

## 저장
- `challenge: { day: string | null, marks: string }`. 끝까지 푼 판만 기록한다. 중간에 나가면 다시 풀 수 있다(의도한 동작: 실수로 나간 사람을 막지 않는다).
- 오늘의 문제도 낱알·문제 기록·연속 기록·하루 목표에 똑같이 들어간다.

## 화면
- 홈: 큰 시작 버튼 위에 "오늘의 문제 #n · 5문제" 카드. 풀었으면 "🟩🟩🟥🟩⏰ 3/5 · 공유하기"로 바뀌고 누르면 공유.
- 게임: 오늘 이미 풀었으면 문제를 내지 않고 안내한다.
- 결과: 오늘의 문제였으면 칸 표시와 "결과 공유" 버튼.
