# 공부 기능 1차 ('모르겠어요'·오답노트·간격 복습·유형 연습)

## 목적
출퇴근길에 잠깐 푸는 사람은 놓친 문제가 알아서 다시 나오게 하고, 시험·대회를 준비하는 사람은 약한 부분을 직접 찾아 파고들 수 있게 한다. 같은 규칙(간격 복습) 하나로 두 부류를 함께 챙긴다.

- 하는 것: '모르겠어요' 버튼, 간격 복습(1→3→7일, 세 번 맞히면 외움), 오답노트 화면(⭐ 담기 포함), 약한 유형만 푸는 연습 판.
- 하지 않는 것: 시간·하트 없는 공부 모드(써 보고 필요하면 나중에), 계정·서버 동기화, 문제 내용 수정(콘텐츠는 웹 저장소).
- 실패로 보는 것: 짧게 푸는 흐름이 무거워지는 것(일반 판에 단계가 늘거나 팝업이 생김), 예전 기록이 사라지는 것.

## 접근 (고른 것: B)
- A. 오답노트 화면만: 가장 작지만 한 번 맞히면 노트에서 빠지는 약점이 남는다.
- **B. 오답노트 + 간격 복습 + 약한 유형 연습**: 잠깐 푸는 사람은 일반 판에 복습이 섞여 따로 할 일이 없고, 파고드는 사람은 노트와 유형 연습을 쓴다. ← 선택
- C. B + 시간·하트 없는 공부 모드: 짧은 퀴즈 앱 성격이 흐려지고 모드가 늘어 이번엔 뺀다.

## 규칙 (`src/core/`, 순수 함수, 테스트 먼저)

### '모르겠어요' (`round.ts`)
- `giveUp(round, now)`: 오답과 똑같이 처리한다(하트 -1, 연속 정답 끊김, 낱알 0, 오답 기록). `RoundResult`에 `gaveUp: boolean`을 더한다(`timedOut`은 false, `userAnswer`는 '').
- 오늘의 문제 공유 칸에서는 🟥(`x`). 별도 표시를 만들지 않는다.

### 간격 복습 (`progress.ts`)
`QuestionStat`에 더한다: `box: 0|1|2|3`(0=노트에 없음), `dueDay: string | null`(다음 복습 날, 기기 날짜 `YYYY-MM-DD`), `wrong: number`(틀린 횟수), `lastAnswer?: string`(마지막으로 틀린 내 답, 모르겠어요·시간 초과면 비움), `lastMiss?: 'wrong'|'timeout'|'giveup'`, `starred?: boolean`, `mastered?: boolean`.

- 틀림(오답·시간 초과·모르겠어요): `box = 1`, `dueDay = 오늘 + 1일`, `wrong + 1`, `mastered = false`.
- 맞힘, 노트에 있고 `dueDay <= 오늘`: box 1→2(+3일), 2→3(+7일), 3→외움(`box = 0`, `dueDay = null`, `mastered = true`).
- 맞힘, 아직 복습 날이 아님: 단계를 바꾸지 않는다(같은 날 여러 번 풀어 바로 외움 처리되는 것을 막는다. 벌점도 없음).
- 맞힘, 노트에 없음: 지금처럼 맞힌 횟수만 센다.
- `needsReview`는 `box > 0`과 같은 뜻으로 남긴다(기존 코드·테스트 호환). 결국 `box`에서 계산해도 된다 — 구현 판단.
- 날짜 계산은 `growth.ts`의 `localDay`·`dayDiff`를 쓴다(ms 비교 대신 날짜 단위, "내일 복습"이 자정 기준으로 맞게).

### 예전 저장 옮기기 (`save.ts`의 `loadSave`)
- 스키마 번호는 그대로 1. 읽을 때 빠진 필드를 채운다.
- `needsReview: true`면 `box = 1`, `dueDay = localDay(lastWrongAt) + 1일`, `wrong = max(1, seen - correct)`. 아니면 `box = 0`, `dueDay = null`, `wrong = seen - correct`.

### 출제 (`picker.ts`)
- 일반 판: 지금처럼 복습 문제를 최대 2개 섞되, 기준을 "하루 지난 오답"에서 "`dueDay <= 오늘`인 노트 문제(오래 밀린 순)"로 바꾼다.
- 복습 판(`pickReviewRound`): 복습 날이 된 문제 먼저(밀린 순), 모자라면 아직 날이 안 된 노트 문제(최근에 틀린 순)로 10개.
- ⭐ 판(`pickStarredRound`): 담은 문제에서 오래전에 푼 순(`lastAt` 작은 순) 10개(외운 문제 포함).
- 판 도중 처음 보는 문제에 ⭐를 누르면 `seen: 0`인 기록이 먼저 생길 수 있다. 판을 끝내면 평소처럼 채워지고, 판을 그만둬도 ⭐ 목록에는 남는다(`lastAt` 0은 맨 앞).
- 유형 연습 판(`pickTypeRound(type)`): 그 유형만으로 10개. 복습 날이 된 노트 문제 → 안 푼 문제 → 오래전에 푼 문제 순. 쉬운 문제 우선 규칙은 쓰지 않는다(파고드는 사람용).
- 모든 판은 예전처럼 보기를 섞는다. 묶음이 바뀌어 없어진 key는 건너뛴다.

### 노트 목록 (`progress.ts`의 `notebook(p, questions, filter)`)
- `filter`: `'review'`(노트에 있는 문제: 복습 날 된 것 먼저, 그다음 다음 복습 날 순) · `'starred'` · `'mastered'`(외운 문제, 최근 순).
- 개수 함수: 노트 전체 수, 오늘 복습할 수(`dueDay <= 오늘`).

## 화면

### 게임 (`PlayScreen`)
- 답 입력 아래에 작은 회색 텍스트 버튼 **"모르겠어요"**. 누르면 곧바로 오답 피드백이 나오고 판정 문구는 "모르겠어요"(빨간색), 정답·해설은 오답과 같다. 확인 창은 띄우지 않는다.
- 피드백 카드 오른쪽 위에 **☆/⭐** 담기 버튼(맞힌 문제도 담을 수 있다). 누르면 바로 저장되고 판 진행에는 영향 없다. 카드 전체를 눌러 넘기는 동작과 겹치지 않게 별 버튼은 따로 누름 영역을 갖는다.
- 테스트 모드 버튼은 그대로.

### 홈
- "틀린 문제 다시 풀기 (N)" 자리를 **"오답노트 · 오늘 복습 N"**으로 바꾼다. 누르면 오답노트 화면. 노트가 비어도 누를 수 있다(⭐·외운 문제를 보러).

```
[ 📅 오늘의 문제 #12          ]
[ ▶ 한 판 시작                ]
[ 📒 오답노트 · 오늘 복습 3    ]
```

### 오답노트 (새 화면 `src/app/notebook.tsx`)
```
‹ 뒤로        오답노트
[복습할 문제 12] [⭐ 담은 문제 4] [외운 문제 7]     ← 탭
[ ▶ 복습 풀기 (오늘 3) ]                          ← 탭에 따라 '⭐ 풀기'
┌────────────────────────────────┐
│ 뜻 맞히기 · 오늘 복습   ●○○  ⭐ │
│ '살갑다'의 뜻은?               │  ← 눌러서 펼치기
│ 정답: 마음씨가 부드럽고 상냥하다 │
│ 내 답: 쌀쌀하다 · 틀린 횟수 2    │
│ 해설 …                         │
└────────────────────────────────┘
```
- 행: 유형, 복습 상태("오늘 복습" 또는 "n일 뒤", 단계 점 ●○○), ⭐ 버튼, 문제 첫 두 줄. 누르면 정답·내 답(모르겠어요/시간 초과면 그 말)·틀린 횟수·해설·출처가 펼쳐진다.
- 빈 탭은 한 줄 안내("틀린 문제가 여기에 모여요" 등).
- 풀기 버튼은 문제 수가 0이면 흐리게.

### 기록
- 유형별 정답률 행을 누르면 **그 유형 연습 판**(10문제·하트 3). 행에 "연습 ›" 표시.

### 결과
- 판 모드 이름: 복습 판 "복습 끝!", 유형 연습 "○○ 연습 끝!". 그 외는 지금과 같다.
- "틀린 문제 보기" 카드에 모르겠어요면 "모르겠어요"로 표시, ⭐ 버튼 추가.
- 이번 판에서 외운 문제가 있으면 안내 줄 맨 앞에 "📒 n문제를 외웠어요".

## 기록·목표와의 관계
- 모든 판(일반·복습·⭐·유형 연습·오늘의 문제)이 문제 기록과 간격 복습에 반영된다(지금처럼).
- 하루 목표·연속 기록·낱알은 판 종류와 관계없이 지금 규칙 그대로 센다. `RoundMode`에 `'starred' | 'practice'`를 더한다.

## 구현자에게 맡기는 것
- 스타일 세부, 탭 컴포넌트 모양, 펼치기 애니메이션 여부.
- `needsReview`를 필드로 둘지 `box`에서 계산할지.
- 별 담기를 `GameProvider`의 `toggleStar(key)`로 둘지 이름.

## 내가 정한 것 (확인 필요 시 고칠 수 있음)
- 간격 1→3→7일, 세 번 맞히면 외움. 복습 날 전에 맞히면 단계 유지.
- 일반 판 복습 섞기 최대 2개 유지.
- '모르겠어요'는 확인 창 없이 바로.
- ⭐는 간격 복습과 별개 목록(틀리지 않아도 담을 수 있음).
