# 오늘의 낱말 · 곳간 낱말 · 학습 알림

작성일: 2026-11-20 · 근거: [콘텐츠 확장·경험 개선 방안](../../2026-11-20-content-expansion-ideas.md) 3단계(C4·E2·E4)

## 오늘의 낱말 (C4)

- **묶음**: 웹 `scripts/lib/app-pack.mjs`의 `appCards`가 자체 학습 낱말(쓰임 학습 중 `word`·`examples`가 있고 확인 문제 `usage:<id>`가 묶음에 있는 것, 현재 36개)을 `cards` 선택 필드로 싣는다. 카드: `key, word, title, pos, meaning, explain, tip, examples, question`. 카드가 있으면 묶음 `version`에 카드 내용도 들어간다. `minApp`은 그대로(옛 앱은 `cards`를 무시).
- **앱 검사**(`pack.ts`): `cards`는 선택. 잘못된 카드만 빼고 묶음은 받는다.
- **고르기**(`cards.ts`의 `cardOfDay`): key 순으로 정렬해 `CHALLENGE_EPOCH`부터 날마다 하나씩 돌아간다. 모두에게 같은 카드.
- **화면**: 홈의 "오늘의 낱말" 줄 → `/card`. 뜻·쓰임 설명·예문·팁을 읽고 아래 확인 문제(보기형 쓰임 문제)를 바로 푼다. 고르면 보기마다 이유(해설의 "보기: 이유" 줄)를 펼친다.
- **기록**(`save.ts`의 `finishCard`): 문제 기록만 남긴다(틀리면 오답노트). 판 수·낱알·하루 목표·연속 기록은 세지 않는다. `card.day`로 오늘 풀었는지 표시하고, 다시 열면 정답과 이유를 펼쳐 둔다.

## 곳간 낱말 (E2)

- `collection.ts`의 `wordCollection`: 외운 문제(간격 복습 완료)의 정답 낱말을 `normalizeAnswer` 기준으로 하나씩 모으고, 맞혀 본 낱말 수를 센다. 정답이 낱말인 유형만(뜻·첫소리·맞춤법). 띄어쓰기·쓰임은 문장이라 빼고, 속담은 활용형 빈칸이라 뺀다.
- 화면 `/collection`(기록 화면의 "곳간 낱말" 줄에서): 외운 낱말·맞혀 본 낱말 수, 낱말 칩, 누르면 해설.
- 새 저장 항목 없음(기존 문제 기록에서 계산).

## 학습 알림 (E4)

- `expo-notifications`(SDK 58), `app.json`에 플러그인과 `POST_NOTIFICATIONS` 권한. 서버 푸시 없음.
- 설정 "학습 알림"(기본 꺼짐) + 시각(오전 8시·오후 12시·7시·9시, 기본 오후 7시). 켤 때 권한을 묻고, 거절하면 켜지 않는다.
- `reminder.ts`의 `planReminder`: 오늘 아직 안 풀었고 시각 전이면 오늘, 아니면 내일 같은 시각. 글: 복습할 문제 수(그날 기준) → 없으면 연속 기록 → 없으면 한 판 권하기.
- `GameProvider`가 기록·설정이 바뀔 때마다 예약을 모두 지우고 다음 한 번만 다시 예약한다(`data/reminder.ts`). 앱을 오래 안 열면 마지막 예약 한 번만 울린다.

## 내가 정한 것 (고칠 수 있음)

- 카드 확인 문제는 하루 목표·연속 기록에 세지 않는다(1문제로 목표를 채우지 않게).
- 알림은 하루 한 번, 반복 예약 대신 "다음 한 번"만 둔다(글에 그날의 복습 수를 넣으려고).
- 곳간 낱말은 기록 화면에서 연다(홈은 자리가 좁다).

## 확인이 필요한 것

- 알림은 실제 기기에서 확인하지 않았다(Jest는 모의 모듈). 새 빌드(`eas build`)가 필요하다.
